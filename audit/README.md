# Review records

No reviews have been performed. Use one record per accepted book, recording
the reviewed source/translation revisions, date, actual contributors/models,
clause-by-clause findings, changes, declined findings and reasons, remaining
uncertainties, and acceptance decision. Link it from the manifest.

Structural checks enforce references and recorded coverage. Human/editorial
review must still assess fidelity, English, annotation, and completeness of
the source inventory. Proofreading a transcription is not a new textual edition.
